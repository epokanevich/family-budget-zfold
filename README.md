# Семейный Бюджет (Z Fold 4/5 Edition) — Нативный Android-проект

Персональное приложение для общего семейного бюджета **Евгения и Анжелики** без деления на долги и без платных подписок.

## Что реализовано внутри
1. **Единый семейный котёл в рублях (`₽`)**: без сложных сплитов 50/50 и взаиморасчётов.
2. **Адаптивный интерфейс под Samsung Galaxy Z Fold 4/5**:
   - На **внешнем (сложенном) экране** — компактный интерфейс с нижней навигацией.
   - На **внутреннем (разложенном) экране** — двухпанельный режим: слева очередь пушей и лента трат, справа — сводка бюджета и ИИ-аналитик.
3. **Бесконфликтная синхронизация (Offline-First Room + Firebase Firestore)**:
   - Каждая трата сохраняется как отдельный документ со своим `UUIDv4` и флагом `isDeleted` (Soft Delete).
   - Два телефона никогда не затирают траты друг друга даже после долгого офлайна.
4. **Автоперехват пушей строго по белому списку (`BankPushListenerService`)**:
   - Слушает **только** пакеты СберБанка (`ru.sberbankmobile`) и Mir Pay (`ru.nspk.mirpay`).
   - **Т-Банк полностью исключён** (корпоративная карта не попадёт в семейный бюджет).
   - Встроенная защита от дублей (если за одну покупку пришёл пуш и от Mir Pay, и от Сбера в пределах 90 секунд — запишется только одна трата).
5. **Сканер QR-кодов чеков ФНС РФ (`CameraX` + `ML Kit`)**:
   - Мгновенно считывает сумму и дату из любого кассового чека (`t=...&s=...`).
6. **Гибридный ИИ-аналитик трат**:
   - Офлайн-модуль считает темп расходов по дню месяца и показывает, **где перебор**, а **в каких категориях есть запас**, чтобы порадовать себя.
   - Опционально подключается бесплатный ключ Google Gemini API для текстового разбора недели.

## Как получить готовый `.apk` за 5 минут (без установки программ на ПК)

### Шаг 1. Создайте бесплатную базу синхронизации в Firebase (0 ₽)
1. Откройте [Firebase Console](https://console.firebase.google.com/) и нажмите **Create a project** (любое название, например `family-budget-pokanevich`).
2. В меню слева выберите **Build → Firestore Database → Create database**:
   - Выберите любую локацию (например, `eur3`) и режим **Start in test mode** (или в вкладке **Rules** укажите `allow read, write: if true;`).
3. На главной странице проекта нажмите на иконку **Android**, укажите пакет:
   ```
   ru.pokanevich.familybudget
   ```
4. Скачайте файл **`google-services.json`**.

### Шаг 2. Загрузите проект на GitHub и скачайте готовый APK
1. Создайте бесплатный приватный репозиторий на [GitHub](https://github.com/new).
2. Распакуйте этот архив и загрузите все его файлы в репозиторий (через кнопку **Add file → Upload files** прямо в браузере).
3. Положите скачанный из Firebase файл `google-services.json` в папку `app/google-services.json` (если не положить, сборка всё равно пройдёт успешно для офлайн-работы).
4. Перейдите во вкладку **Actions** вашего репозитория — там автоматически запустится задача **Build FamilyBudget APK**.
5. Через 3–4 минуты скачайте готовый **`app-debug.apk`** из раздела **Releases** (справа на главной странице репозитория) или из артефактов сборки, установите себе на Z Fold и перешлите Анжелике в Telegram/WhatsApp.

### Шаг 3. Первая настройка на двух телефонах
1. Откройте приложение, нажмите на шестерёнку **⚙️ (Настройки)**:
   - На своём телефоне выберите **«Евгений»**, на телефоне жены — **«Анжелика»**.
   - Убедитесь, что поле **«Общий код семьи»** одинаковое на обоих телефонах (по умолчанию `POKANE-FAMILY`).
2. Нажмите **«Дать доступ к уведомлениям»** и включите тумблер напротив **«Семейный Бюджет»** (чтобы приложение могло ловить пуши СберБанка и Mir Pay).
   - *Примечание для Android 13+ при установке APK вручную:* если переключатель доступа к уведомлениям неактивен, откройте `Настройки телефона → Приложения → Семейный Бюджет → меню (три точки в углу) → Разрешить ограниченные настройки`, после чего включите доступ к уведомлениям.
